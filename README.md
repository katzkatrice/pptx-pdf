# PHP Vercel Starter

Project PHP sederhana yang siap di-deploy ke Vercel melalui GitHub.

## Struktur

- `api/index.php` - entry point PHP
- `vercel.json` - konfigurasi runtime PHP Vercel

## Deploy melalui GitHub

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder project ini.
3. Di Vercel pilih **Add New Project**.
4. Import repository GitHub tersebut.
5. Klik **Deploy**.

Tidak perlu mengubah `Build Command` untuk project sederhana ini.

## Catatan

Project ini menggunakan `vercel-php@0.9.0`.
